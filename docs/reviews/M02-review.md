## B. Spec conformance — verified by reading the code

- **Uniform error (`error.rs:8-11`, `:14-18`, `:21-27`):** the single variant `Rejected`, `Display` "rejected", crypto errors fold into it; nothing formats input bytes (unconditional `Debug` only on `Error` and `Period`, `wire/mod.rs:41`; key types redacted, `keys.rs:25-33`).
- **Exact fit, trailing bytes rejected:** `Decode::decode` ends in `finish` (`codec.rs:205-210`, `:96-102`); records check `len` against the fixed body size, then the type (`record.rs:32-40`).
- **Bounded reads, no unchecked arithmetic:** `take` goes through `split_at_checked` (`codec.rs:28-32`), prefixes through `usize::from` (`:79-88`); no `as`, no `+`/`-`/`*` outside tests except one compile-time assertion (`inv.rs:504`); deny set `lib.rs:20-27`; no recursion, allocation within the input size (lists ≤ 255, FETCH_MULTI ≤ 32, `frame.rs:342-345`).
- **Presence and boolean bytes 0/1 only** (`codec.rs:61-67`); Options strict both ways: RelayRef direct (`inv.rs:152-160`), avatar (`:282`), OK_SEND (`frame.rs:682-692`), LINK_GET zero signature in mode 0 and checked signature in mode 1 (`:368-380`).
- **ISO/IEC 7816-4 padding** (`codec.rs:217-245`): exact size, last non-zero byte 0x80, zero tail, fields fit exactly; frames 4336 (`frame.rs:430-439`, `:734-742`), Content 1710 (`cell.rs:723-726`), LinkDataV1 12288 (`inv.rs:452-455`), Outer 12018 (`hx.rs:109-113`).
- **`ver` rule (§4.1)** wherever App. D lists it, nested occurrences included: HELLO `record.rs:87`, RelayInfoV1 `:128`, HS1 `:226`, HS2 `:275`, RelayRef `inv.rs:148`, InvitationV1 `:213`, IKSPublic `:313`, PrekeyBundle `:366`, LinkDataV1 `:435`, Outer `hx.rs:90`, HeaderV1 `cell.rs:123`, RouteDescriptor `:411`, Content `:707`.
- **Decoder obligation (a), X25519:** all 9 fields go through `X25519Pk` (`keys.rs:44-48`, `:66-69`), which refuses the 14 low-order encodings (`x25519.rs:129-139`).
- **Decoder obligation (b), Ed25519:** the five key fields reject y ≥ p, order dividing 8 and off-curve points (`keys.rs:81-85` → `ed25519.rs:169-176`); `R` and `S < L` are checked for every D.2 signature, RelayInfoV1 `sig` and HybridSig bytes 0–63 (`keys.rs:119-122`, `:156-162` → `ed25519.rs:210-222`); the ML-DSA half stays opaque, no sigDecode (`keys.rs:146-162`, `inv.rs:297`).
- **Decoder obligation (c), ML-KEM:** all 6 `ek` fields pass the FIPS 203 §7.2 modulus check (`keys.rs:197-200` → `mlkem.rs:112-119` → libcrux `validate_public_key`).
- **Value rules:** onion VERSION 0x03 and valid checksum (`inv.rs:40-52`); direct host 1..=253 bytes in 0x21..=0x7E, port ≠ 0 (`:88-95`, `:155`); InvitationV1 `kind` 1 (`:215`); `Profile.name` ≤ 64 bytes strict UTF-8 (`:276-281`); `opk_present` 1 (`:373`); `flags` 0 (`cell.rs:125`); `caps` 0 (`:480`); counts 1..=255 (`:241-255`); Fragment 2 ≤ total ≤ 64, idx < total, chunk ≥ 1 (`:302-311`); Content body ≤ 1689, Dummy empty, unfragmented 0x05 rejects (`:684`, `:712`, `:652-663`); inner types {2,4,5,6,7} (`:771-781`); periods in PERIODS (`wire/mod.rs:72-77`); HandshakeCellPlaintext i < 3, total 3 (`hx.rs:198-211`); CONT idx ∈ {1,2}, exactly 4100 bytes (`frame.rs:121-151`); FETCH_MULTI count 1..=32 (`:340-344`); CELLR zero-field and context rules (`:566-592`).

- **Sizes:** 40 `const _: () = assert!` (`sizes.rs:195-257`) plus `inv.rs:504`, each re-derived from its D field list and cross-checked against `secmp-crypto`; together they cover every App. B row. The differential over 187 248 mutants found 0 disagreements and 0 accepted-but-non-canonical inputs. The red team hand-checked negative families the lens had not (RSV `enc-0219`/`0220`/`0271`, OVF `enc-0538`): each isolates exactly the stated D.2/D.5 rule; it read all non-test code of `wire/frame.rs`, `wire/cell.rs`, `codec.rs`, `inv.rs` (Onion/Host/RelayRef/Profile), `wire/mod.rs` and the `secmp-crypto` input paths `ed25519.rs:150-230`, `x25519.rs:120-145` and found no missed blocker.
