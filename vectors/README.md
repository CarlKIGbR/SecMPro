# vectors/ — frozen SecMP test vectors

JSON test vectors (positive and negative) for every construction and wire structure (spec Appendix C), in the
format of `SCHEMA.md`, generated by the Rust implementation **and** the independent reference in `ref/`, and
frozen only when both agree (ADR-026). Initial generation happens in M1–M5; afterwards a frozen vector changes
only with a spec revision (CLAUDE.md §1.10).

| Path | Content | Written by |
|---|---|---|
| `SCHEMA.md` | the normative format and case tables | reviewer |
| `ref/<suite>.json` | reference files of the independent Python implementation (`ref/`, separate session; CI never runs it) | the `ref/` session, copied in by the reviewer/owner |
| `rust/<suite>.json` | the Rust side (gitignored) | `cargo xtask vectors` (example `gen-vectors` of `secmp-crypto`, feature `kat`) |
| `<suite>.json` | **frozen** files: the reference file, verbatim, after the Rust file matched it structurally (SCHEMA §1) | `cargo xtask vectors` |
| `external/` | vendored Wycheproof and NIST ACVP known-answer vectors with provenance (`external/SOURCES.md`) | implementer |

Checks: `cargo xtask vectors` (generate, compare, freeze; never overwrites a frozen file); the `kat` step
re-generates every frozen suite on every target (`crates/secmp-crypto/tests/vectors.rs`); `ci-full` step 12a
compares the frozen files with `ref/` (`cargo xtask step ref-vectors`).

Status (M1): `hkdf-labels`, `caead`, `msgencrypt`, `hybridkem-768`, `hybridkem-1024`, `hybridsign`, `fingerprint`,
`sas` — 118 cases, identical between Rust and `ref/` on the first comparison, frozen 2026-09-28.
