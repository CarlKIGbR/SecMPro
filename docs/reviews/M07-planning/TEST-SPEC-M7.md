## Conventions (apply to every row)

- **Clock.** `secmp_client_core::clock::{ManualClock, SystemClock}` as in M6; virtual milliseconds unless "real". No
  unit test reads a wall clock (`docs/06` §4); real time only in E2-01…E2-04, E2-06…E2-09, CL-* (child processes).
- **Argon2id parameters.** Every row uses `Argon2Params::kat_small()` (m = 64 KiB, t = 1, p = 1; constructor exists
  only with feature `kat`) except ST-07 (the shipped constant) and CT-03 (informative, real parameters) [O-15].
- **Profiles on disk.** Every store row runs on a fresh temporary directory (`tempdir` from the testkit helpers, no new
  crate); file listings are taken with `std::fs`. A row never shells out to `strings`/`hexdump`: FO-01 implements both
  scans in Rust (printable runs ≥ 4 bytes; raw byte search).
- **Crash points (kat).** `secmp_store::kat::CrashAt::{AfterCommitBeforeWrite, AfterWriteBeforeOkSend, MidTxn(k),
  AfterDecryptBeforeCommit, AfterCommitBeforeAck}`; a child process (`std::process::Command` on the test binary with
  `--exact <row> --ignored`-free re-entry via an env-selected role) calls `std::process::abort()` at the point. The
  parent reopens the profile from disk. `kat` only; `ST-09`/`CL-12` prove no `kat` in shipped builds.
- **Failure injection (kat).** `secmp_store::kat::FailAt(statement k)` makes the k-th SQL statement of the next
  transaction return an error.
- **Canary set** (FO-01, BK-02, AP-05): message text `CANARY-MSG-<16 hex>` (ASCII, UTF-8, UTF-16LE), contact display
  name `Zebulon-Canary-<8 hex>`, own name, both fingerprints (raw 32 B, lower/upper hex), the 60 SAS digits, every
  `IKSPublic` component (raw), `MK_profile`, `KEK`, the nine table keys, `rk` and the current `ck_s`/`ck_r`/`hk_*` and
  the last 16 message keys (kat accessors), the invitation `link_key`, the full invitation URI, the passphrase.
- **Counting accessors (kat):** M6's `tr_encrypt_calls`, `persist_calls` plus `argon2_calls`, `caead_open_calls`,
  `store_txn_commits`, `store_bytes_written`.
- **Est.** = expected runtime on the 4-vCPU runner; rows ≥ 60 s are candidates for `MUTANT_HARNESS_SKIP_TESTS`.
