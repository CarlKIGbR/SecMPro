## Verdicts

| FID | Severity | Status | Reason | Smallest fix |
|---|---|---|---|---|
| L8-01 | major | CONFIRMED (reproduction + code reading) | Unbounded thread-per-connection with `std::thread::spawn` on the main thread; spawn refusal panics → process dies; 512 idle unauthenticated connections under TasksMax=512; every crash empties the relay | Atomic connection counter / semaphore checked before spawning (cap well below TasksMax and LimitNOFILE, e.g. 400), over the cap close the stream; `std::thread::Builder::spawn` with `Err` → close the stream; set `LimitNOFILE` explicitly in docs/05 §4 |
| L8-02 | major | CONFIRMED (reproduction; test pins it) | Any accept error except WouldBlock/Interrupted exits serve → process; EMFILE reachable with idle connections; `serve_fails_on_a_listener_error` pins `ConnectionAborted` as fatal | Retry (sleep `ACCEPT_POLL`) on `EMFILE`/`ENFILE`/`ENOBUFS`/`ENOMEM`/`ConnectionAborted`/`ConnectionReset` and the accept(2) pending-network errors; exit only on `EBADF`/`EINVAL`/`ENOTSOCK`; change the test to assert retry for these kinds |
| L8-03 | minor | CONFIRMED (code reading) | Linked connections have no inactivity bound and `write_all` has no write timeout, so non-reading/idle links hold threads forever; becomes a lockout of the cap once L8-01 is fixed (cost: 1 HELLO token each, 4/s) | `set_write_timeout` in `set_poll`; relay-side idle bound for `Phase::Linked` (no unit within k × slowest period, or link age > LINK_LIFETIME + margin) |

Note (outside the three FIDs): `docs/01:158` names "Tor PoW" as a DoS mitigation while `docs/05:39` has PoW off (ADR-024); `docs/05` torrc lacks `HiddenServiceMaxStreams` / `HiddenServiceMaxStreamsCloseCircuit 1` (relevant to L8-04 too).
