Registers (LTO passes the arguments split): x0/x1 = base pointer/length, x2/x3 = the delta slice's pointer/length,
w4 = class, x5/x6 = out pointer/length.

Finding: one loop, not versioned on the mask or the class. The mask is computed without a branch
(`orr w8, w4, #0xfe; add w8, w8, #0x1`: low byte 0xFF for an even class, 0x00 for an odd one), stored to the stack
and reloaded (`strb w8, [sp, #0xf]` … `ldrb w8, [sp, #0xf]`: `black_box(m)`); the delta slice goes through memory
the same way (`stp x2, x3, [sp, #0x10]` … `ldr x9, [sp, #0x18]`, `ldr x10, [sp, #0x10]`). The mask is broadcast into a
vector register (`dup.16b v0, w8` at 0x100030664; `dup.8b v0, w8` at 0x1000306cc for the 8-byte tail) and enters the
XOR only through `and` (main loop 0x100030678–0x1000306b4, 64 B per iteration: `ldp` delta, `and.16b` with v0, `ldp`
base, `eor.16b`, `stp` out; then an 8-byte and a 1-byte tail, `and w13, w8, w13` in the latter). Every conditional
branch tests a length or a loop counter (`cbz x9`, `cmp x9, #0x8`/`#0x40` + `b.hs`, `subs`/`adds` + `b.ne`,
`cmp x9, x11` + `b.eq`, `cbz x12`); w8 is never compared and no branch depends on it or on w4. The loop length is
the minimum of the three slice lengths, the same for both classes. No `bl` in the symbol, so no `memcpy`. Both
classes therefore execute the same instructions on the same addresses (`base`, the one delta, `out`) and differ only
in the value of w8. The fallback of the Weisung (`black_box(m)` inside the loop body) was not needed.
