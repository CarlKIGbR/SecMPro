# vectors/ — frozen SecMP test vectors

JSON test vectors (positive and negative) for every construction and wire structure (spec Appendix C),
generated by `cargo xtask vectors` from the Rust implementation **and** the independent reference in `ref/`,
and frozen only when both agree byte-for-byte (ADR-026). Initial generation happens in M1–M5; afterwards a
frozen vector changes only with a spec revision (CLAUDE.md §1.10).

Status: empty in M0.
